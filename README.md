# 지혜의 미로 탐험대

Vite + Phaser 게임입니다. GitHub Pages는 게임 파일을 배포하고, Supabase는 교실별 학습자료와 학생의 맵별 최신 플레이 기록을 보관합니다. 재배포 시 Supabase 자료는 유지됩니다.

## 최초 설정 (한 번)

1. https://supabase.com/dashboard 에서 새 프로젝트를 만듭니다. 가까운 지역을 선택합니다.
2. SQL Editor에서 `supabase/schema.sql` 전체를 실행합니다. 신규 프로젝트용 스크립트이므로 이미 설치한 경우 다시 실행하지 않습니다.
3. Authentication → Sign In / Providers에서 **Allow new users to sign up**을 켭니다. 같은 화면의 **Email** 설정에서 **Confirm email**을 끄고 저장합니다. 이 설정은 이름으로 가입하는 방식을 사용하기 위해 최초 한 번 필요합니다. Email 로그인 제공자는 켜 둡니다.
4. 프로젝트 설정에서 Project URL과 **publishable key**를 복사합니다. 기존 프로젝트의 `anon` 키도 지원합니다. **secret / service_role 키는 사용하지 않습니다.**
5. GitHub 저장소 Settings → Secrets and variables → Actions → **Variables**에 아래 두 항목을 등록합니다.
   - `VITE_SUPABASE_URL`: `https://프로젝트ID.supabase.co`
   - `VITE_SUPABASE_PUBLISHABLE_KEY`: 공개 publishable key 또는 기존 anon 키
6. GitHub Actions에서 `Deploy Vite to GitHub Pages`를 다시 실행합니다. 최초 설정 이후 일반 코드 배포 시 별도 CSV 업로드가 필요 없습니다.
7. 교사용 설정에서 이름·비밀번호를 입력하고 **교사 계정 만들기**를 누릅니다. 이후에는 같은 이름·비밀번호로 로그인합니다. 교실 이름 입력 → 교실 생성 → CSV 업로드 후 **학생 입장 QR 크게 보기** 버튼으로 교실 QR을 띄웁니다.

설정이 없으면 기존 개인 연습 모드와 PIN(기본 1234)을 사용할 수 있습니다. 이 PIN은 로컬 편집용이며 Supabase 접근 권한을 주지 않습니다. 교사 인증 토큰은 탭의 sessionStorage에 보관합니다.

## CSV

UTF-8 CSV 형식:

```csv
map,type,english,korean
MAP01,word,door,문
MAP01,expression,Open the door.,문을 여세요.
```

전체 업로드에는 MAP01~MAP12 **모두** 단어와 표현을 각각 4~20개, 중복 없이 입력합니다. 각 항목에 한국어 뜻이 필요합니다. 교사용 화면의 `CSV 양식 다운로드`로 양식을 받아 편집하고, 학급을 선택한 뒤 CSV 파일을 업로드하면 자동으로 저장됩니다. 별도의 저장 버튼이나 맵별 편집은 필요하지 않습니다. 기존 자료를 교체할 때만 확인창이 표시됩니다.

## 학생 및 기록

- 입장 링크의 `?classroom=ABCD12` 또는 등록 화면의 교실 코드를 사용합니다. 코드를 비워 두면 개인 연습입니다.
- 교실의 전체 자료를 읽은 뒤 게임을 시작합니다. 교실이 없거나 자료가 불완전하거나 네트워크가 실패하면 오류를 표시하며 다른 자료로 대체하지 않습니다.
- 새 모험마다 새 학생 입장 ID가 만들어집니다. 닉네임이 같아도 기록은 섞이지 않습니다. 이어하기는 같은 기기·브라우저의 학생 입장 정보를 사용합니다. 다른 기기 이어하기는 지원하지 않습니다.
- 맵별 이름, 경과 시간(초), 제시 문제 수, **첫 시도 정답 수**, 오답 시도 수, 힌트 사용 수, 완료 여부를 저장합니다. 시간은 기존 게임의 세션 시작 시각 기준 경과 시간이며 대기 시간도 포함합니다.
- 진행 저장 지점마다 최신 상태를 전송하며, 완료 전 기록도 저장됩니다. 맵별 마지막 상태를 갱신하므로 개별 문항 응답 내역이나 매번의 플레이 이력을 저장하는 방식은 아닙니다.
- 연결이 끊기면 전송 대기 자료를 localStorage에 남기고 15초마다 또는 연결 복구 시 재전송합니다. 브라우저를 닫으면 다음 게임 실행 때 재전송됩니다. 기기 저장소를 지우면 미전송 기록과 이어하기 정보는 사라집니다.
- 교사는 선택한 학급의 랭킹을 조회합니다. 기록은 페이지 단위로 모두 불러오며 15초마다 갱신합니다. 학생은 다른 학생의 이름이나 기록을 조회할 수 없습니다.
- 교실 코드는 자료 열람·입장을 위한 공유 코드입니다. 학생 이름은 본인 입력값이며 실제 신원을 인증하지 않습니다.

## 개발 및 검증

```sh
cp .env.example .env
# .env에 URL과 공개 키 입력
npm install
npm run dev
npm test
npm run build
```

RLS와 RPC 권한은 `supabase/security-check.sql`로 새 테스트 프로젝트에서 검증할 수 있습니다. 실제 서버에 연결한 뒤 이름으로 교사 가입·로그인 → 교실 생성 → CSV 저장 → 학생 링크 입장 → 정답/오답/힌트 사용 → 기록 조회 → 네트워크 차단/재연결을 확인하세요.

`src/cloud.js`는 Supabase REST·인증·재전송을, `src/data.js`는 맵 데이터와 로컬 캐시를, `src/admin.js`는 교사 화면을 담당합니다. `src/game/Map01Scene.js`~`Map12Scene.js`의 기존 게임 동작을 유지합니다.

## 퀴즈 키보드 조작

객관식은 방향키로 선택지를 이동하고 스페이스바 또는 Enter로 제출합니다. 아직 선택지가 없으면 첫 방향키 입력으로 첫 선택지를 고릅니다. 문장 만들기는 방향키로 단어와 다시 선택·확인 버튼 사이를 이동하고 스페이스바 또는 Enter로 누릅니다. 단어를 고르면 다음 단어로, 모든 단어를 고르면 확인 버튼으로 초점이 이동합니다. 마우스·터치도 함께 사용할 수 있습니다.

교사용 실제 로그인 비밀번호는 Supabase Authentication에서 설정·변경합니다. 공개 저장소에는 비밀번호를 기록하지 않습니다.

## 이름으로 교사 가입·로그인

교사는 이메일을 입력하거나 이메일 인증을 할 필요 없이 이름과 비밀번호(8자 이상)만 입력합니다. 이름은 공백 정리·유니코드 정규화·영문 소문자화를 거쳐 고유 로그인 ID로 사용합니다. 다른 교사와 이름이 겹치면 학교명 등을 붙여 다른 이름을 사용하세요. 이름 변경은 다른 로그인 ID가 되므로 같은 이름으로 로그인해야 합니다.

내부적으로 Supabase Auth를 그대로 사용하며 이름의 SHA-256 해시를 메일을 받지 않는 내부 이메일 형식의 식별자로 변환합니다. 비밀번호는 Auth에만 전달되고 브라우저 저장소나 저장소 코드에는 보관하지 않습니다. 기존 이메일 계정은 이름 칸에 기존 이메일을 입력해서 로그인할 수도 있습니다. 비밀번호 복구 이메일은 지원하지 않으며 프로젝트 관리자가 Authentication → Users에서 관리합니다.

기존 SQL 설치를 다시 실행할 필요는 없습니다. 교실 및 학생 기록의 소유자별 RLS 정책은 그대로 적용됩니다. 큰 QR 창에는 교실 이름·교실 코드·학생 입장 QR이 표시되며 닫기 버튼이나 Esc로 닫을 수 있습니다.

## 랭킹과 키보드 조작

교사용 화면은 학급 선택 → CSV 업로드 → 학생 입장 QR 순서로 구성됩니다. 새 학급은 빈 자료로 만들어집니다. 오른쪽에서 참여 학생 수, 최근 1분 내 기록 저장 학생 수, 완료 맵 수와 랭킹을 확인합니다. 최근 활동은 실시간 접속 여부가 아닌 마지막 기록 저장 시간 기준입니다.

완료한 맵 점수 = 600 + 반올림(400 × 첫 시도 정답률) − 20 × 오답 횟수 − 10 × 힌트 횟수. 맵당 0~1,000점으로 제한하며 진행 중인 맵은 0점입니다. 학급 내 같은 이름의 맵별 최고 기록을 합산하므로 최대 12,000점입니다. 동명이인은 번호와 이름을 함께 입력하세요. 동일 점수이면 완료 맵 수, 완료 맵 첫 정답률, 완료 맵 플레이 시간 순으로 정하며 이 값이 모두 같으면 공동 순위입니다. 개별 저장 기록의 학생 입장 ID는 그대로 유지됩니다.

MAP01~12 모두 E / Enter / Space로 조사합니다. 영어 퀴즈는 방향키로 선택하고 Space 또는 Enter로 확인합니다. 대화창에서도 Space / Enter로 진행할 수 있으며 창을 조작한 키는 맵 조사로 동시에 전달되지 않습니다.

## 학급·계정 삭제

`선택한 학급 삭제`는 확인 코드 입력 후 해당 학급과 연결된 학생·기록을 영구 삭제합니다. 기존 RLS로 본인 소유 학급만 삭제할 수 있습니다. `계정 삭제`는 확인 문구와 현재 비밀번호를 입력하고 본인 계정과 소유 학급·기록을 모두 삭제합니다. 다른 교사의 계정을 삭제하는 기능은 없습니다.

**기존 프로젝트는 계정 삭제용으로 `supabase/account-deletion.sql`만 한 번 실행하세요.** `schema.sql` 전체를 다시 실행하지 마세요. 신규 프로젝트용 전체 스키마에는 이 함수가 포함되어 있습니다. 함수는 사용자 ID를 인수로 받지 않고 `auth.uid()`의 계정만 삭제하며 익명 호출을 허용하지 않습니다. 삭제한 자료는 앱에서 복구할 수 없습니다.

## 클릭·터치와 게임 효과

12개 맵에서 바닥을 클릭하거나 터치하면 해당 위치로 이동합니다. 물건을 누르면 조사 범위까지 이동한 뒤 해당 물건을 조사합니다. MAP01은 기존 충돌벽을 피하는 격자 경로를 사용하며 통과할 수 없는 위치는 이동하지 않습니다. 키보드·가상 방향키를 누르면 클릭 이동이 취소됩니다. 대화·퀴즈·보스전 중 맵 포인터 입력은 차단됩니다.

가까운 조사 물건에는 금빛 표시와 Space/클릭·터치 안내가 나옵니다. 체크는 **살펴본 물건**을 뜻하며 정답이나 퀘스트 완료를 뜻하지 않습니다. 조각 수는 HUD에 0/3~3/3으로 표시하고, 새로 획득한 조각만 수집칸으로 날아갑니다. 이어하기의 기존 조각에는 획득 효과를 재생하지 않습니다.

객관식·문장 만들기는 답을 누른 뒤 약 0.5초 동안 정답/재도전 문구와 부드러운 소리·입자를 표시합니다. 이때 중복 제출은 차단하고 이후 기존 게임 흐름을 이어갑니다. `효과음 켜짐/꺼짐` 버튼은 기기에 설정을 기억합니다. 브라우저의 모션 줄이기 설정은 입자·비행·흔들림을 줄입니다. 효과음은 사용자 클릭이나 키 입력 이후 Web Audio로 재생하며 오디오를 지원하지 않아도 게임을 계속할 수 있습니다.
